#DESCRIPTION
This project is a responsive Weather Dashboard web application that fetches and displays real-time weather data for any city entered by the user. Built using HTML, CSS, and JavaScript, the application integrates the OpenWeatherMap API to retrieve current weather conditions such as temperature, weather description, humidity, and wind speed. When a user inputs a city name and clicks the "Get Weather" button, the application sends a request to the API and dynamically updates the webpage with the latest weather information. The interface is clean, mobile-friendly, and includes basic error handling to guide users if the input is invalid or the city is not found. This project demonstrates how to integrate a third-party API into a modern web application.
